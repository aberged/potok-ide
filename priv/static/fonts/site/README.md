# Fonts for sites

Served at `/fonts/site/` for the Sajt app's themes (`fonts.css`). Copied byte for byte
from the `@fontsource-variable` npm packages listed below (Google Fonts' own subsets:
Latin, Latin Extended, Cyrillic; normal and italic where the family has one).
None of these families reserves its name in its licence, so serving subsets is fine
(Comfortaa, Playfair Display, Lora, Merriweather and Raleway do, and were left out).

| Noto Sans | `@fontsource-variable/noto-sans@5.3.0` | sans | SIL OFL 1.1 |
